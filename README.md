<h1 align="center">Towardsalah</h1>
<p align="center">A gentle Salah reminder that lives on your desktop.<br>Free for Windows, Mac &amp; Linux · prayer times calculated on your computer.</p>

## Download

Get the newest version from **[Releases → Latest](../../releases/latest)**:

- **Windows 10 / 11:** `Towardsalah-Windows-Setup.exe`
- **Mac (Apple Silicon and Intel, macOS 12+):** `Towardsalah-macOS.dmg`
- **Linux — Ubuntu, Linux Mint, Debian:** `Towardsalah-Linux.deb` · **other distros:** `Towardsalah-Linux.AppImage`

### First install

The installers are not code-signed yet, so your computer warns you once:

- **Windows:** "Windows protected your PC" → **More info** → **Run anyway**.
- **Mac:** open the .dmg and drag Towardsalah into Applications. Open it once; when macOS says it
  "cannot be verified", click **Done**, then open **System Settings → Privacy & Security**, scroll down
  and click **Open Anyway** next to Towardsalah.
- **Linux:** no warning. `.deb`: double-click → **Install** (or `sudo apt install ./Towardsalah-Linux.deb`).
  AppImage: right-click → Properties → **Allow executing as program**, then double-click
  (recent Ubuntu may first need `sudo apt install libfuse2`, or `libfuse2t64` on 24.04).
